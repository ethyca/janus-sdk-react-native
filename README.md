# Janus SDK for React Native

The Janus SDK provides privacy-first consent management for mobile applications. The React Native SDK wraps the native Janus SDKs for iOS and Android, so React Native apps can:

- Serve appropriate privacy notices based on user location
- Collect and manage user consent preferences
- Enforce consent across the application
- Synchronize consent state with your backend systems

> **Status:** not yet released. This repository will hold tagged releases of the React Native SDK. Installation instructions and an implementation guide will be added with the first release.

## Requirements

- React Native 0.81 or later, with the New Architecture
- iOS 15.0 or later
- Android API 24 or later
